# nfelo

nfelo is a power ranking, prediction, and betting model for the NFL. Nfelo takes 538's Elo framework and further adapts it for the NFL, hence the name nfelo (pronounced "NFL oh").

The model's output is visualized on [nfeloapp.com](https://www.nfeloapp.com) where you can explore:
* [Weekly Predictions](https://www.nfeloapp.com/games)
* [Current Power rankings](https://www.nfeloapp.com/nfl-power-ratings)
* [The QB model](https://www.nfeloapp.com/qb-rankings)
* [Analysis behind nfelo's ideas](https://www.nfeloapp.com/analysis)

## Model code has moved private

As of November 11th, 2026, this repository no longer contains the nfelo model source and will not receive new source updates. This repository will continue to receive the same model outputs in the output_data/ folder on the same cadence. These files will run from updated versions of the model, even though the source for that model will not be public. Current consumers of files in output_data/ will not be affected by this change.

The package now is meerly a fetch utility for CSVs generated by the nfelo model.

## Output files

Files live in `output_data/`:

| File | Description |
|---|---|
| `nfelo_games.csv` | Game-level nfelo ratings, projections, cover probabilities, EV, and market fields used by downstream pipelines |
| `historic_projected_spreads.csv` | Append-only ledger of weekly pre-game projections to see the model at a timestamped point in time |
| `elo_snapshot.csv` | Current team elo snapshot derived |
| `prediction_tracker.csv` | Compact current-week projection table (teams, projected spread, win probability) |
